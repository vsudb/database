#  Установка и настройка учебной БД PostgreSQL 
##  [DataBase Schema](https://github.com/vsudb/database/blob/main/schema/img_schema_vsudb.png)

## 1. Локальная установка PostgreSQL и pgAdmin4

1. **Скачайте установщик для вашей ОС:** [EnterpriseDB](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads) last version
2. **Задайте пароль:** В процессе установки программа потребует ввести пароль администратора (`postgres`). Для удобства рекомендуется использовать единый пароль: `123456`. _Студенты часто забывают сложные пароли. Я не экстрасенс. Смена пароля трудоемкая операция._
3. **Завершение установки:** После окончания процесса автоматически запустится утилита *Application Stack Builder*. Она предназначена для установки дополнительных расширений, для текущих учебных задач она **не нужна** — просто закройте это окно.
4. Видеоинструкция: [VK](https://vkvideo.ru/video-232636783_456239019)

## 2. Развертывание локальной базы данных

1. Запустите приложение **pgAdmin4**.
2. Подключитесь к вашему локальному серверу PostgreSQL, используя заданный ранее пароль (`123456`).
3. Создайте базу данных _Create --> Database..._ **vsudb** _(наименование потребуется для подключения через IDE)_
4. Скачайте [pg_migration_study.sql](https://github.com/vsudb/database/blob/main/schema/pg_migration_study.sql) 
- это SQL-скрипт Максима Котельникова из Moodle (раздел «Управление данными»)
4. Откройте **Query Tool** (Редактор SQL), вставьте содержимое скрипта и выполните его.
5. После успешного выполнения в базе данных должно появиться **6 таблиц**. Проверить корректность создания можно простым запросом:
   ```sql
   SELECT * FROM student;
   ```

## 3. Подключение к серверу Postgres через сторонние IDE

Вы можете работать с созданной базой данных через любую удобную среду разработки (это дело вкуса).

| Параметр подключения | Значение | Примечание |
| :--- | :--- | :--- |
| **Host** (Хост) | `localhost` | Локальный сервер |
| **Database** (База данных) | `postgres` или `vsudb` | В зависимости от указанного имени |
| **Username** (Пользователь) | `postgres` | Имя суперпользователя по умолчанию |
| **Password** (Пароль) | `123456` | |
| **Port** (Порт) | `5432` | Стандартный порт PostgreSQL |

### DBeaver
1. Скачайте и установите [DBeaver](https://dbeaver.io/).
2. Создайте новое соединение, выбрав тип **PostgreSQL**.
3. Укажите параметры подключения. 
4. Видеоинструкция: [VK](https://vk.com/video-232636783_456239017).

### VSCode
1. Установите расширение **SQLTools** и плагин **SQLTools PostgreSQL**.
2. Настройте новое подключение к локальному серверу по аналогичным параметрам.
3. Видеоинструкция: [VK](https://vk.com/video-232636783_456239018).

### JetBrains DataGrip (самое лучшее авто дополнение кода) 
1. Скачайте и установите [DataGrip](https://www.jetbrains.com/datagrip/download/?section=windows)
2. Инструкция как получить лицензию [for non commercial use](https://blog.jetbrains.com/datagrip/2025/10/01/datagrip-is-now-free-for-non-commercial-use).
3. Настройте новое подключение к локальному серверу по аналогичным параметрам.

## 4. Альтернативный вариант: Развертывание БД в облаке (Supabase)

Если вы хотите иметь доступ к своей базе данных из любого места без локальной установки, используйте платформу [Supabase](https://supabase.com/).

### Пошаговый алгоритм:
1. **Регистрация:** Создайте аккаунт на сайте [Supabase](https://supabase.com/) через электронную почту или аккаунт GitHub.
2. **Создание проекта:** Создайте новый проект, укажите его имя и задайте простой пароль для базы данных.
3. **Создание структуры:** Перейдите в раздел **SQL Editor**, вставьте структуру таблиц из файла [create_table.sql](https://github.com/vsudb/database/blob/main/schema/create_vsudb.sql) и запустите выполнение. Это создаст необходимые 6 таблиц.
4. **Импорт данных:** 
   * Скачайте учебные данные для таблиц CSV-файлы: [seeds](https://github.com/vsudb/database/tree/main/seeds).
   * Перейдите в **Table Editor**, выберите поочередно каждую из 6 таблиц и загрузите в них соответствующие CSV-файлы через функцию **Import Data from CSV**. *Важно соблюдать правильный порядок импорта из-за зависимостей (внешних ключей).*
5. **Проверка:** После импорта вы можете писать и выполнять любые `SELECT` запросы прямо в веб-интерфейсе SQL Editor.

* Видеоинструкция по деплою в облако: [VK](https://vk.com/wall-232636783_5).

---
> **Важно:** На первом очном занятии в классе мы подключимся к серверу баз данных **Oracle**. 
В классе могут быть проблемы с подключением. Поэтому у каждого должен быть аккаунт в Supabase и развернутая Postgres на localhost.
Если у вас возникнут трудности с самостоятельным развертыванием PostgreSQL или Supabase на ноутбуках, мы разберем и настроим все вместе.
