#  Установка и настройка учебной БД PostgreSQL

## 1. Локальная установка PostgreSQL и pgAdmin4

1. **Скачайте установщик для вашей ОС:** [EnterpriseDB](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads) last version
2. **Задайте пароль:** В процессе установки программа потребует ввести пароль администратора (`postgres`). Для удобства рекомендуется использовать единый пароль: `123456`. _Студенты часто забывают сложные пароли. Я не экстрасенс. Смена пароля трудоемкая операция._
3. **Завершение установки:** После окончания процесса автоматически запустится утилита *Application Stack Builder*. Она предназначена для установки дополнительных расширений, для текущих учебных задач она **не нужна** — просто закройте это окно.

## 2. Развертывание локальной базы данных

1. Запустите приложение **pgAdmin4**.
2. Подключитесь к вашему локальному серверу PostgreSQL, используя заданный ранее пароль (`123456`).
3. Скачайте schema/pg_migration_study.sql SQL-скрипт Максима Котельникова из Moodle (раздел «Управление данными») или найдите его по ссылке во [VK](https://vk.com/wall-232636783_1).
4. Откройте **Query Tool** (Редактор SQL), вставьте содержимое скрипта и выполните его.
5. После успешного выполнения в базе данных должно появиться **6 таблиц**. Проверить корректность создания можно простым запросом:
   ```sql
   SELECT * FROM student;
   ```

## 3. Подключение через сторонние IDE

Вы можете работать с созданной базой данных через любую удобную среду разработки.

### Вариант А: DBeaver
1. Скачайте и установите [DBeaver](https://dbeaver.io/).
2. Создайте новое соединение, выбрав тип **PostgreSQL**.
3. Укажите параметры подключения (Host: `localhost`, Database: `postgres`, Username: `postgres`, Password: `123456`).
4. Подробная видеоинструкция: [Смотреть во ВКонтакте](https://vk.com/video-232636783_456239017).

### Вариант Б: VSCode
1. Установите расширение **SQLTools** и плагин **SQLTools PostgreSQL**.
2. Настройте новое подключение к локальному серверу по аналогичным параметрам.
3. Подробная видеоинструкция: [Смотреть во ВКонтакте](https://vk.com/video-232636783_456239018).

## 4. Альтернативный вариант: Развертывание БД в облаке (Supabase)

Если вы хотите иметь доступ к своей базе данных из любого места без локальной установки, используйте платформу [Supabase](https://supabase.com/).

### Пошаговый алгоритм:
1. **Регистрация:** Создайте аккаунт на сайте [Supabase](https://supabase.com/) через электронную почту или аккаунт GitHub.
2. **Создание проекта:** Создайте новый проект, укажите его имя и задайте простой, но надежный пароль для базы данных.
3. **Создание структуры:** Перейдите в раздел **SQL Editor**, вставьте структуру таблиц из файла `create_table.sql` и запустите выполнение. Это создаст необходимые 6 таблиц.
4. **Импорт данных:** 
   * Скачайте учебные CSV-файлы из документов группы: [vk.com/docs-232636783](https://vk.com).
   * Перейдите в **Table Editor**, выберите поочередно каждую из 6 таблиц и загрузите в них соответствующие CSV-файлы через функцию **Import Data from CSV**. *Важно соблюдать правильный порядок импорта из-за зависимостей (внешних ключей).*
5. **Проверка:** После импорта вы можете писать и выполнять любые `SELECT` запросы прямо в веб-интерфейсе SQL Editor.

* Видеоинструкция по деплою в облако: [Смотреть во ВКонтакте](https://vk.com/wall-232636783_5).
