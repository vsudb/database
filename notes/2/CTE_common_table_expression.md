# CTE Общее/Обобщенное табличное выражение

**CTE (Common Table Expression)** — это временная именованная таблица (или результат запроса), которая существует только в рамках одного SQL-запроса.

## Что это такое простыми словами

Представь, что тебе нужно выполнить сложный запрос с несколькими промежуточными расчётами. Вместо того чтобы писать огромные вложенные подзапросы (которые трудно читать и поддерживать), ты можешь «вынести» эти промежуточные результаты в отдельные именованные блоки с помощью конструкции `WITH`.

Эти блоки называются **CTE**. Они:
- Существуют только во время выполнения текущего запроса
- Могут ссылаться друг на друга (в определённом порядке)
- Делают код гораздо более читаемым и логичным

## Синтаксис

```sql
WITH 
    имя_cte1 AS (
        -- любой SELECT
    ),
    имя_cte2 AS (
        -- любой SELECT, может использовать предыдущие CTE
    )
SELECT ...
FROM ...
```

## Пример

```sql
WITH student_avg_marks AS (
-- 1. Первый подзапрос: Расчет средней оценки каждого студента
    SELECT 
        student_id,
        AVG(mark) AS avg_mark
    FROM exam_marks
    GROUP BY student_id
),
university_stats AS (
-- 2. Второй подзапрос: Агрегация данных по университетам
    SELECT 
        s.univ_id,
        COUNT(s.student_id) AS total_students,
        AVG(sam.avg_mark) AS univ_avg_mark
    FROM student s
    JOIN student_avg_marks sam ON s.student_id = sam.student_id
    GROUP BY s.univ_id
),
lecturer_loads AS (
-- 3. Третий подзапрос: Выборка топ-преподавателей для каждого университета (по количеству ведомых предметов)
    SELECT 
        l.univ_id,
        COUNT(sl.subj_id) AS total_lectures_taught
    FROM lecturer l
    JOIN subj_lect sl ON l.lecturer_id = sl.lecturer_id
    GROUP BY l.univ_id
)
SELECT 
    u.univ_name,
    u.city,
    u.rating,
    COALESCE(us.total_students, 0) AS students_count,
    ROUND(COALESCE(us.univ_avg_mark, 0), 2) AS average_score,
    COALESCE(ll.total_lectures_taught, 0) AS total_courses_conducted
FROM university u
LEFT JOIN university_stats us ON u.univ_id = us.univ_id
LEFT JOIN lecturer_loads ll ON u.univ_id = ll.univ_id
ORDER BY u.rating DESC;
```

### Разбор примера

1. **`student_avg_marks`**  
   Считает среднюю оценку каждого студента.

2. **`university_stats`**  
   Использует предыдущий CTE, чтобы посчитать для каждого университета:
   - количество студентов
   - среднюю оценку по университету

3. **`lecturer_loads`**  
   Считает, сколько предметов ведут преподаватели в каждом университете.

После всех CTE идёт основной `SELECT`, который соединяет эти результаты с таблицей `university` и выводит итоговую статистику.

## Преимущества CTE

- **Читаемость** — код разбит на логические шаги
- **Повторное использование** — один и тот же CTE можно использовать несколько раз в основном запросе
- **Рекурсия** — CTE умеют работать рекурсивно (для иерархических данных: деревья, графы и т.д.)
- **Простота отладки** — можно легко проверять каждый шаг отдельно

## Когда использовать

- Когда запрос становится слишком сложным из-за вложенных подзапросов
- Когда нужно выполнить несколько последовательных агрегаций
- Когда хочется сделать код понятным другим разработчикам (и себе через полгода)

## Важные моменты

- CTE **не сохраняется** в базе — это временная конструкция
- В одном запросе можно объявить несколько CTE через запятую
- Порядок важен: CTE может ссылаться только на те, которые объявлены **выше** него

---

**Краткий итог**:  
CTE (`WITH ... AS (...)`) — это способ давать имена промежуточным результатам запроса, чтобы сделать сложный SQL понятным, структурированным и удобным для поддержки.
