# Подробное описание схемы базы данных (VSUDB)

![Схема базы данных VSUDB](https://raw.githubusercontent.com/vsudb/database/main/schema/img_schema_vsudb.png)

Данная схема описывает реляционную базу данных, предназначенную для учета учебного процесса в университетах: информацию о ВУЗах, студентах, преподавателях, изучаемых дисциплинах и результатах сдачи экзаменов.

---

## 1. Таблицы и их структура

### 1.1 `UNIVERSITY` (Университеты)
Содержит информацию об учебных заведениях.

| Поле | Тип данных | Ключ | Описание |
| :--- | :--- | :--- | :--- |
| `UNIV_ID` | `INT` | **PK** | Уникальный идентификатор университета |
| `UNIV_NAME` | `VARCHAR` | | Название университета |
| `RATING` | `INT` | | Рейтинг университета |
| `CITY` | `VARCHAR` | | Город расположения ВУЗа |

---

### 1.2 `STUDENT` (Студенты)
Хранит персональные данные студентов и их привязку к университету.

| Поле | Тип данных | Ключ | Описание |
| :--- | :--- | :--- | :--- |
| `STUDENT_ID` | `INT` | **PK** | Уникальный идентификатор студента |
| `SURNAME` | `VARCHAR` | | Фамилия студента |
| `NAME` | `VARCHAR` | | Имя студента |
| `STIPEND` | `INT` | | Размер стипендии |
| `KURS` | `INT` | | Номер курса обучения |
| `CITY` | `VARCHAR` | | Город проживания / рождения |
| `BIRTHDAY` | `DATE` | | Дата рождения |
| `UNIV_ID` | `INT` | **FK** | Ссылка на ВУЗ (`UNIVERSITY.UNIV_ID`) |

---

### 1.3 `LECTURER` (Преподаватели)
Информация о преподавательском составе.

| Поле | Тип данных | Ключ | Описание |
| :--- | :--- | :--- | :--- |
| `LECTURER_ID` | `INT` | **PK** | Уникальный идентификатор преподавателя |
| `SURNAME` | `VARCHAR` | | Фамилия преподавателя |
| `NAME` | `VARCHAR` | | Имя преподавателя |
| `CITY` | `VARCHAR` | | Город проживания |
| `UNIV_ID` | `INT` | **FK** | Ссылка на ВУЗ (`UNIVERSITY.UNIV_ID`) |

---

### 1.4 `SUBJECT` (Предметы / Дисциплины)
Каталог учебных дисциплин.

| Поле | Тип данных | Ключ | Описание |
| :--- | :--- | :--- | :--- |
| `SUBJ_ID` | `INT` | **PK** | Уникальный идентификатор предмета |
| `SUBJ_NAME` | `VARCHAR` | | Наименование предмета |
| `SEMESTER` | `INT` | | Номер семестра |
| `HOUR` | `INT` | | Объем дисциплины в академических часах |

---

### 1.5 `EXAM_MARKS` (Оценки по предметам)
Таблица результатов сдачи экзаменов (связывающая таблица между студентами и предметами).

| Поле | Тип данных | Ключ | Описание |
| :--- | :--- | :--- | :--- |
| `EXAM_ID` | `INT` | **PK** | Идентификатор экзаменационной ведомости/записи |
| `STUDENT_ID` | `INT` | **PK, FK** | Ссылка на студента (`STUDENT.STUDENT_ID`) |
| `SUBJ_ID` | `INT` | **PK, FK** | Ссылка на предмет (`SUBJECT.SUBJ_ID`) |
| `MARK` | `INT` | | Полученная оценка |
| `EXAM_DATE` | `DATE` | | Дата сдачи экзамена |

---

### 1.6 `SUBJ_LECT` (Назначение предметов преподавателям)
Связывающая таблица, определяющая, какие преподаватели ведут какие дисциплины.

| Поле | Тип данных | Ключ | Описание |
| :--- | :--- | :--- | :--- |
| `SUBJ_ID` | `INT` | **PK, FK** | Ссылка на предмет (`SUBJECT.SUBJ_ID`) |
| `LECTURER_ID` | `INT` | **PK, FK** | Ссылка на преподавателя (`LECTURER.LECTURER_ID`) |

---

## 2. Связи и отношения между таблицами

1. **`UNIVERSITY` — `STUDENT` (Один ко многим / $1:N$)**
   * Один университет может обучать множество студентов.
   * Каждый студент относится только к одному университету (`STUDENT.UNIV_ID` -> `UNIVERSITY.UNIV_ID`).

2. **`UNIVERSITY` — `LECTURER` (Один ко многим / $1:N$)**
   * В одном университете работает множество преподавателей.
   * Каждый преподаватель числится в конкретном ВУЗе (`LECTURER.UNIV_ID` -> `UNIVERSITY.UNIV_ID`).

3. **`STUDENT` — `SUBJECT` (Многие ко многим / $M:N$)**
   * Реализовано через связующую таблицу **`EXAM_MARKS`**.
   * Один студент может сдавать экзамены по множеству предметов, и один предмет может быть сдан многими студентами.

4. **`SUBJECT` — `LECTURER` (Многие ко многим / $M:N$)**
   * Реализовано через связующую таблицу **`SUBJ_LECT`**.
   * Преподаватель может вести несколько предметов, а один и тот же предмет может преподаваться несколькими преподавателями.
